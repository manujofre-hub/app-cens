# Lista de imágenes de la Clase 3: Software, internet y seguridad
Carpeta destino: imagenes/teoria-tic-3/
Formato: WebP o JPG (máximo 800 px para capturas, 1200 px para fotos, peso menor a 200 KB).

========================================================================
TEMA 1: ¿Qué es el software? (a01)
========================================================================
1. c3-soft-01.webp
   - Qué debe mostrar: Ilustración o foto conceptual mostrando una laptop moderna de la cual flotan iconos luminosos de programas y código digital (representando la parte lógica intangible).
   - Prompt IA: "A modern laptop open on a clean desk, with glowing holographic application icons and code floating out of the screen, conceptual technology, bright clean background, 4k resolution, high quality, editorial tech photography."

TEMA 2: Sistemas operativos (a02)
========================================================================
2. c3-so-windows.webp
   - Qué debe mostrar: Captura de pantalla de Windows 10 u 11 con el menú Inicio desplegado y el escritorio limpio.
   - Consejo: Captura de pantalla real de una compu del aula (recortada a 800x600 o similar).

3. c3-so-macos.webp
   - Qué debe mostrar: Escritorio de Apple macOS con el Dock de aplicaciones visible abajo.
   - Prompt IA: "Clean desktop screenshot of macOS interface with bottom dock and minimalist desktop wallpaper, high quality."

4. c3-so-linux.webp
   - Qué debe mostrar: Escritorio de Linux (Huayra de Conectar Igualdad, o Ubuntu/Mint).
   - Consejo: Captura de pantalla de una netbook de la escuela con Huayra.

5. c3-so-android.webp
   - Qué debe mostrar: Pantalla de inicio de un teléfono móvil Android con iconos de apps ordenados y reloj.
   - Consejo: Captura directa de celular sin datos privados.

6. c3-so-ios.webp
   - Qué debe mostrar: Pantalla de inicio de un iPhone con su cuadrícula de apps característica.
   - Prompt IA: "Front view of modern iPhone screen interface displaying colorful app grid on a clean abstract wallpaper, high resolution."
